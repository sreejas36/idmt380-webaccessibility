Optimizing My Portfolio Website for Web Accessibility

Project Overview

In a world of growing internet accessibility, it is important to make sure you are growing with it.

In my IDM T380 Web Accessibility class, I learned to apply various accessibility principles in order to optimize my personal portfolio and expand my knowledge on how to make websites accessible for all.

Role

Designer, Developer

Duration

10 Week Project
January 2026 - March 2026

Tools & Methods

Figma, VS Code

Deliverables

3 responsive pages employing web accessibility principles, including aria labels, respecting user preferences, and a dynamic form.

🔍 Overview

I worked to redesign my portfolio to make it fully web accessible. Taking web accessibility principles, I revamped my home page, gallery, and contact page, redefining my color palette to respect user preferences, implementing aria labels and related semantics, and developing a web accessible form. This project taught me a lot of new aspect of accessibility and code, while helping me curate my personal brand.

🤺 Context and Challenge

This project had many ups and downs, where I knew what I wanted to implement from the start, but wasn't able to pursue the project the way I would've liked. Due to a personal emergency, I had been backed up with assignments, and took a bit more time to get them completed. But I put a lot of time and effort into completing the necessary parts and fully succeeding to have a proper project.

🎯 Goals & Objectives

My goals for this project were to:

  • Have a week by week demonstration of how web accessibility is built from the ground up
  • Achieve a proper deliverable of fully responsible and web accessible 3 pages
  • Implement my personal brand by learning and applying various web accesible tools to make it happen

🚦 Process and Insight

Every week, we learned a new aspect of web accessibility and applied it to our chosen site.

1️⃣ Color Palette

Our first week, we developed a color palette that would properly reflect our brand. Initially I developed these color combinations, but that changed through trial end error. I didn't like the colors I picked for my initial dark mode, so I adjusted it to a navy blue as my primary dark color.

Robust Color Palette
Accessible Color Contrast Options Palette

2️⃣ Initial Website Building

After that, we took a deeper look at our chosen site and stripped it of its CSS, remaking the HTML and CSS to match our accessible color theme.

Week 2 HW

3️⃣ Including Accessibility

This is where we started delving into Web Accessibility. I added ARIA labels and semantic HTML to replace my current structure and make the website further accessible.

This is also where I added one of my favorite findings; respect user preferences. With this, I was able to switch from light to dark mode on demand, and I really loved how it made my site come to life.

Week 3 HW

4️⃣ Web Accessible Form

This was one of the most interesting parts of the project, as well as the one that took me the most time. We were to create a web accessible form; one that would only accept the proper inputs, and give errors if the requirements were not met. It was my first time making a form, so it took a bit of practice. But it works all well!
